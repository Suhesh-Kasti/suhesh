# SQL

Grouped by what you're doing: reading data, writing data, or changing the schema. Keywords are capitalized but SQL doesn't care.

## Reading data

### SELECT

Pull columns from a table.

```sql
SELECT column1, column2 FROM table_name WHERE condition;
```

### WHERE

Filter rows. Combine conditions with AND, OR, NOT.

```sql
SELECT * FROM table_name WHERE condition;
```

### DISTINCT

Drop duplicate rows.

```sql
SELECT DISTINCT column1 FROM table_name;
```

### ORDER BY

Sort the result. ASC is the default, DESC reverses it.

```sql
SELECT * FROM table_name ORDER BY column1 ASC;
```

### COUNT

Count the rows that match.

```sql
SELECT COUNT(*) FROM table_name WHERE condition;
```

### GROUP BY

Bucket rows by a value, usually so you can aggregate each bucket.

```sql
SELECT column1, COUNT(*) FROM table_name GROUP BY column1;
```

### HAVING

Filter the output of GROUP BY. WHERE can't see aggregates, HAVING can.

```sql
SELECT column1, COUNT(*) FROM table_name GROUP BY column1 HAVING COUNT(*) > 1;
```

### JOIN

Combine rows from two tables on a matching column.

```sql
SELECT * FROM table1 JOIN table2 ON table1.column_name = table2.column_name;
```

## Writing data

### INSERT

Add new rows.

```sql
INSERT INTO table_name (column1, column2) VALUES (value1, value2);
```

### UPDATE

Change existing rows. Keep the WHERE or you rewrite the whole table.

```sql
UPDATE table_name SET column1 = value1 WHERE condition;
```

### DELETE

Remove rows. Same warning about WHERE.

```sql
DELETE FROM table_name WHERE condition;
```

## Schema

### CREATE TABLE

Define a new table with its columns and types.

```sql
CREATE TABLE table_name (
  column1 datatype,
  column2 datatype
);
```

### ALTER TABLE

Add, change, or drop a column.

```sql
ALTER TABLE table_name ADD column_name datatype;
```

### DROP TABLE

Delete the table and its data. No undo.

```sql
DROP TABLE table_name;
```

### CREATE INDEX

Speed up lookups on a column, at the cost of slower writes.

```sql
CREATE INDEX index_name ON table_name (column1, column2);
```
