Commands grouped by what you're trying to do. Everything below assumes you're inside the repo directory.

## Setup and clones

### git init

Start tracking the current folder as a new repository.

```bash
git init
```

### git clone

Copy a remote repository to your machine.

```bash
git clone repository_url
```

### git remote

Point a local repo at a remote.

```bash
git remote add origin repository_url
```

## Staging and committing

### git status

See what's changed and what's already staged.

```bash
git status
```

### git add

Stage files for the next commit.

```bash
git add file_name   # one file
git add .           # everything under the current directory
```

### git commit

Record the staged changes with a message.

```bash
git commit -m "Your commit message"
```

### git diff

Show unstaged changes line by line. Add `--staged` to see what's about to be committed.

```bash
git diff
git diff --staged
```

## Branches

### git branch

List branches. Give it a name to create one, or `-d` to delete.

```bash
git branch branch_name
```

### git checkout

Switch branches, or restore a file to an earlier state.

```bash
git checkout branch_name
git checkout -b new_branch   # create and switch in one step
```

### git merge

Fold another branch into the current one.

```bash
git merge branch_name
```

## Remotes

### git fetch

Download new commits and refs without touching your working tree.

```bash
git fetch origin
```

### git pull

Fetch and merge in one step.

```bash
git pull origin branch_name
```

### git push

Send your commits to the remote.

```bash
git push origin branch_name
```

## Undo and history

### git log

Walk the commit history. `--oneline --graph` keeps it readable.

```bash
git log
git log --oneline --graph
```

### git reset

Move HEAD. `--soft` keeps your changes staged, `--mixed` unstages them, `--hard` throws them away.

```bash
git reset --soft commit_hash
git reset --hard commit_hash
```

### git revert

Make a new commit that reverses an old one. Safe on branches other people already have.

```bash
git revert commit_hash
```

### git stash

Park uncommitted work and get a clean tree back.

```bash
git stash push -m "work in progress"
git stash pop
```

<Accordion title="Tags, cherry-pick, and help">

### git tag

Mark a specific commit as a release.

```bash
git tag -a v1.0 -m "Release version 1.0"
```

### git cherry-pick

Apply one commit from another branch onto the current one.

```bash
git cherry-pick commit_hash
```

### git help

Open the manual for any command.

```bash
git help command_name
```
