# Lab: Information disclosure on debug page

## Objective
This lab contains an information disclosure vulnerability on a debug page that exposes sensitive information. To solve the lab, obtain and submit the `SECRET_KEY` environment variable.

## Why This Works (The Principle)
- **The vulnerability:** Debug endpoints or pages are left exposed in production, revealing sensitive configuration data.
- **Root cause:** Development/debug features are not removed or restricted before deployment to production.
- **Exploitation:** Locate and access the debug page to retrieve leaked credentials or configuration values.
- **Key insight:** Always check for common debug paths (`/debug`, `/phpinfo.php`, `/console`, `.env`) during recon.
