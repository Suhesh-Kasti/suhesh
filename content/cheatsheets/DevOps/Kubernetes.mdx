kubectl verbs grouped by the object you're touching. Every command assumes a kubeconfig already points at the cluster.

## Pods

### kubectl run

Start a single pod from an image.

```bash
kubectl run mypod --image=nginx
```

### kubectl get pods

List pods in the current namespace. Add `-A` for every namespace.

```bash
kubectl get pods
kubectl get pods -A
```

### kubectl describe pod

Dump the full state of a pod: events, mounts, container status.

```bash
kubectl describe pod pod_name
```

### kubectl logs

Read a pod's stdout.

```bash
kubectl logs pod_name
kubectl logs -f pod_name   # follow
```

### kubectl delete pod

Kill a pod. If a controller manages it, a new one comes straight back.

```bash
kubectl delete pod pod_name
```

## Deployments and services

### kubectl scale

Change the replica count.

```bash
kubectl scale deployment myapp --replicas=3
```

### kubectl set image

Roll out a new image version.

```bash
kubectl set image deployment/myapp myapp-container=myapp:v2
```

### kubectl expose

Create a service in front of a deployment.

```bash
kubectl expose deployment myapp --port=80 --type=LoadBalancer
```

### kubectl get services

List services and their cluster IPs.

```bash
kubectl get services
```

### kubectl describe service

See endpoints and selector details for a service.

```bash
kubectl describe service service_name
```

### kubectl delete service

Remove a service.

```bash
kubectl delete service service_name
```

## Config and cluster

### kubectl create configmap

Store non-secret config from a file or a literal.

```bash
kubectl create configmap config-map-name --from-file=path/to/config
```

### kubectl create secret

Store sensitive values.

```bash
kubectl create secret generic secret-name --from-literal=key=value
```

### kubectl get nodes

List cluster nodes and their status.

```bash
kubectl get nodes
```

### kubectl create namespace

Make a new namespace to group resources.

```bash
kubectl create namespace my-namespace
```
