# Google Dorking

Search operators that narrow Google down to the interesting stuff on one domain. Reach for these early in recon, before you touch the target, and only against assets you're allowed to test.

<IdeaNode color="#ffdd00">**Keep it cheap:** a dork string is a passive query. The target sees nothing, so there is no reason to skip this step.</IdeaNode>

## Operators

| Operator | Purpose | Example |
|---|---|---|
| `site:` | Restrict results to one domain | `site:target.com` |
| `inurl:` | Match text inside the URL | `inurl:admin` |
| `intitle:` | Match text in the page title | `intitle:"index of"` |
| `intext:` | Match text in the page body | `intext:"sql syntax"` |
| `filetype:` | Limit to a file extension | `filetype:pdf` |
| `ext:` | Alias for filetype in most searches | `ext:bak` |
| `cache:` | Show the cached copy | `cache:target.com` |
| `related:` | Sites similar to a domain | `related:target.com` |
| `inanchor:` | Text inside link anchors | `inanchor:"login"` |
| `"exact phrase"` | Match the phrase exactly | `"password reset"` |
| `-term` | Exclude a term | `site:target.com -www` |
| `OR` | Match either term | `inurl:login OR inurl:signin` |
| `*` | Wildcard for a word | `"index of * backup"` |

## Common recon dorks

### Exposed config and backups

```text
site:target.com ext:env OR ext:bak OR ext:old
site:target.com ext:sql OR ext:db
site:target.com ext:log
site:target.com "config" ext:json
```

### Login and admin panels

```text
site:target.com inurl:login
site:target.com inurl:admin
site:target.com intitle:"admin panel"
site:target.com inurl:signin OR inurl:portal
```

### Open directory listings

```text
intitle:"index of" site:target.com
intitle:"index of" "parent directory" site:target.com
```

### Exposed documents

```text
site:target.com filetype:pdf
site:target.com filetype:xlsx OR filetype:csv
site:target.com ext:docx
```

### Secrets and keys

```text
site:target.com ext:json "api_key"
site:github.com "target.com" "password"
site:pastebin.com "target.com"
```
