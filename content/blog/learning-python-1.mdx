# Python Basics: A Beginner's Guide

Python is one of the easiest languages to start with, and one of the most useful to keep. It reads close to English, it runs without a compile step, and the standard library does a lot before you install anything.

![A short Python program next to the output it prints when run](/images/content/learning-python-1/python01.webp)

## Installing Python

Grab the latest version from [python.org](https://www.python.org/) for Windows, macOS or Linux. On macOS and most Linux distros Python is already there; check with:

```bash
python3 --version
```

## Your First Program

Every Python guide starts here, so we will too:

```python
print("Hello, Python!")
```

Save it as `hello.py` and run it:

```bash
python hello.py
```

`print` is a function, so the parentheses are not optional. The text in quotes is a string. That is the whole language in one line: call something, give it a value.

## Variables and Data Types

A variable is a name pointing at a value. No keyword, no type declaration.

```python
name = "Suhesh"
age = 25
height = 5.9
is_learning = True
```

Python works out the type on its own. The types you'll actually use:

| Data Type | Description | Example |
|-----------|-------------|---------|
| `int` | Whole numbers | `42` |
| `float` | Decimal numbers | `3.14` |
| `str` | Text | `"hello"` |
| `bool` | True or False | `True` |
| `list` | Ordered and changeable | `[1, 2, 3]` |
| `tuple` | Ordered and unchangeable | `(1, 2, 3)` |
| `dict` | Key-value pairs | `{"name": "Suhesh"}` |
| `set` | Unique values, no order | `{1, 2, 3}` |
| `NoneType` | No value at all | `None` |

<IdeaNode color="orange">Indentation is not decoration in Python. Spaces at the start of a line are what define a block. Mix tabs and spaces and you get `IndentationError`, which is Python saying it can't tell what belongs together.</IdeaNode>
