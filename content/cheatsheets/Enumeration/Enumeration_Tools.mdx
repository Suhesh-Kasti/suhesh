# Subdomain Enum Tools

Each tool with the flag you actually run. Passive tools ask third-party databases; active tools resolve and brute-force, so they touch the target.

## subfinder

Fastest passive aggregator. It doesn't scan; it asks other sources what they already know.

### Basic passive discovery

```bash
subfinder -d target.com -silent
```

### Save results to a file

```bash
subfinder -d target.com -o subdomains.txt
```

### Query every source

```bash
subfinder -d target.com -all -o subdomains.txt
```

## amass

Builds a graph of IPs, domains, and ASNs. Slower than subfinder, but deeper passive mapping.

### Passive mode

```bash
amass enum -passive -d target.com
```

### Active mode with brute force

```bash
amass enum -active -d target.com -brute -w /path/to/wordlist.txt
```

## bbot

Correlates findings across modules instead of printing a flat list of names.

### Passive subdomain enumeration

```bash
bbot -t target.com -p subdomain-enum -rf passive
```

## assetfinder

Small Go scraper. Good for a quick pass when subfinder is overkill.

```bash
assetfinder --subs-only target.com > subdomains.txt
```

## Cloud assets

### CloudBrute

Searches AWS, Azure, and GCP for buckets, apps, and storage tied to a company keyword.

```bash
cloudbrute -d target.com -k keyword_list.txt
```

### S3Scanner

Checks a list of bucket names for public access.

```bash
s3scanner scan --bucket-file buckets.txt
```

### Dump an open bucket

```bash
s3scanner dump --bucket target-backup-2026
```
