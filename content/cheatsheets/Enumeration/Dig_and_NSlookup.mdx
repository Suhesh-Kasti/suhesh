Two DNS query tools. `dig` is the Linux default; `nslookup` ships on Windows and is what you use when you only have a Windows shell.

## dig

### All record types

Ask for everything the server is willing to hand over.

```bash
dig target.com ANY
```

### TXT records

SPF, DMARC, and domain-verification strings live here.

```bash
dig target.com TXT
```

### MX records

Mail infrastructure — where email for the domain is delivered.

```bash
dig target.com MX
```

### Query a specific nameserver

Point the query at one server instead of your resolver.

```bash
dig target.com @ns1.target.com
```

### Zone transfer (AXFR)

Pull the whole DNS database if the server allows it. Most don't.

```bash
dig axfr target.com @ns1.target.com
```

### Short output

Just the answer, no header. Handy in a loop.

```bash
dig target.com +short
```

## nslookup (non-interactive)

### Basic lookup

Resolve a name to an address.

```bash
nslookup target.com
```

### Reverse lookup

Turn an IP back into a hostname.

```bash
nslookup 1.1.1.1
```

### Specific record type

Same as `dig MX`, `dig TXT`, and so on.

```bash
nslookup -type=mx target.com
```

### Specific DNS server

Query Google's resolver directly.

```bash
nslookup target.com 8.8.8.8
```

## nslookup (interactive)

Run `nslookup` with no arguments to stay in the prompt and fire off queries without retyping the tool name.

### Change the resolver

```bash
server 8.8.8.8
```

### Pin the record type

```bash
set type=txt
```

### Query

```bash
target.com
```

### Verbose packet output

```bash
set debug
```

### Zone transfer (Windows)

```bash
ls -d target.com
```
