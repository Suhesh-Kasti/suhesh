Three phases of enumeration. Passive first (never touch the target), then semi-passive (use public scanners), then active (direct interaction). If the target's own logs could show a packet from you, it is not passive.

---

## Phase 1: Passive Recon

Read third-party data. Nothing here reaches the target.

```bash
# subdomains from Certificate Transparency logs
curl -s "https://crt.sh/?q=%25.example.com&output=json" | jq -r '.[].name_value' | sort -u

# mail stack and who is allowed to send as the domain
dig +short TXT example.com
dig +short MX example.com

# leaked secrets in code and buckets: use GitHub search and GrayHatWarfare by hand
```

## Phase 2: Semi-Passive

You ask public scanners about the target. The target sees nothing.

```bash
shodan host example.com
# Censys: filter on services and certificates in the web UI
```

<ProgressChecklist checklistId="semi-passive" />

---

## Phase 3: Active Footprinting

Now you send packets at the target. This is the detectable phase.

```bash
nmap -T4 -F example.com            # fast sweep of the most common ports
nmap -sV -p <ports> example.com    # versions on whatever answered
```
