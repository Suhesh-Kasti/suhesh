# Lab: Source code disclosure via backup files

## Objective
This lab leaks its source code via backup files that were left in a publicly accessible directory. To solve the lab, locate the backup files, extract the hard-coded database password, and submit it.

## Why This Works (The Principle)
- **The vulnerability:** Backup copies of source files (`.bak`, `.backup`, `.old`, `.swp`) are left in publicly accessible web directories.
- **Root cause:** Development or deployment processes leave behind temporary/backup files that should not be served to users.
- **Exploitation:** Access the backup files through the web server to read the original source code and find hardcoded credentials.
- **Key insight:** Robots.txt and directory listing can sometimes reveal backup file locations. Always try common backup extensions on known filenames.
