## Objective

To solve this lab, submit a comment that calls the `alert` function when the comment author name is clicked.

## Why This Works (The Principle)
- **The vulnerability:** User-supplied input is embedded into a web page without proper escaping, allowing arbitrary JavaScript execution.
- **Root cause:** The application outputs attacker-controlled data into an HTML context, attribute, or JavaScript context without sanitization.
- **Exploitation:** Inject a payload that escapes the current context (e.g., `>` to break out of an HTML tag, `"` to break out of an attribute).
- **Key insight:** XSS is context-dependent — the same payload will not work in every injection point. Always identify the context first.

## Key Takeaway
_How does an alert trigger if it's supposed to be inside a string being passed to a function?_ It works because of JavaScript's **Order of Evaluation** and **Type Coercion**. JavaScript reads the expression from left to right and attempts to perform mathematical subtraction (the `-` signs) on strings and functions like:
- **Step 1:** The engine sees a math problem involving subtraction operators: `[Value A] - [Value B] - [Value C]`.   
- **Step 2:** It evaluates the first value: `'https://suhesh.com.np'` (a string).
- **Step 3:** It moves to evaluate the second value so it can perform the subtraction. The second value is `alert(1)`.
- **Step 4:** **The alert executes.** To figure out what mathematical value `alert(1)` represents, the JavaScript engine _must_ run the function. The pop-up box appears on the screen.
- **Step 5:** When you close the alert box, the `alert()` function finishes and returns `undefined`.
- **Step 6:** The JavaScript engine tries to do the math: `'https://test' - undefined`. Because you can't subtract `undefined` from a word, the result becomes `NaN` (Not-A-Number).
- **Step 7:** It subtracts the final value (the empty string `''`): `NaN - ''` which remains `NaN`.
- **Step 8:** Finally, it passes that result to the function. The actual code that gets executed at the very end is just `tracker.track(NaN);`.
