## Tools

- [Payload Arsenal](https://suhesh.com.np/tools/payloads): A categorised offensive payload reference for web application testing: cross-site scripting, SQL injection, SSTI, LFI and command injection payloads with bypass techniques, encoding tricks and the context each one is built for.
- [Regex Lab](https://suhesh.com.np/tools/regex): Write and test regular expressions in real time with a plain-English breakdown of every token, capture group and quantifier, plus catastrophic backtracking (ReDoS) detection on the patterns you run.
- [JWT / JOSE Inspector](https://suhesh.com.np/tools/jwt): Decode and verify JSON Web Tokens entirely in your browser. Inspect JWS and JWE headers, claims and signatures, validate HMAC and RSA keys, and audit tokens for alg:none and other classic JWT flaws.
- [Certificate Studio](https://suhesh.com.np/tools/cert): Generate keys and X.509 certificates, build a signing chain, inspect TLS certificates and PEM/DER/PKCS#12 files, and construct mutual-TLS setups for lab environments — all locally, with nothing sent to a server.
- [Crypto Lab](https://suhesh.com.np/tools/crypto): A practical cryptography workbench: SHA and MD5 message digests, HMAC, AES encryption and decryption, base64 and hex encoding, and classical ciphers for CTF work and quick analysis.
- [CVSS Calculator](https://suhesh.com.np/tools/cvss): Build a CVSS vector and get the base score with a breakdown of every metric. Covers exploitability and impact subscores, severity bands and the vector string to paste straight into a report.
- [Hash Identifier](https://suhesh.com.np/tools/hash-id): Paste a hash and identify its likely algorithm from length, character set and known prefixes. Every candidate includes a confidence rating, its hashcat mode and a ready-to-run cracking example.
- [HTTP Security Header Analyzer](https://suhesh.com.np/tools/headers): Analyse HTTP response headers against modern security best practice and get an A–F grade. Checks Content-Security-Policy, HSTS, X-Frame-Options and others, explains the risk of each gap and gives the exact value to set.
- [Hex Dump Analyzer](https://suhesh.com.np/tools/hexdump): Turn raw or copied hex into a readable xxd-style dump. Detect file signatures and magic bytes, measure Shannon entropy to spot packed or encrypted data, and extract printable strings from a binary.
- [Nmap Output Parser](https://suhesh.com.np/tools/ports): Paste nmap XML or grepable output to get a clean per-host summary of open ports, services, versions and findings, grouped and filterable for note-taking and reporting.
- [Recon Suite](https://suhesh.com.np/tools/recon): A combined reconnaissance workbench: enumerate subdomains from a wordlist, resolve DNS records and flag the hosts worth investigating, then pivot into the rest of the toolset from one place.
- [Reverse Shell Generator](https://suhesh.com.np/tools/reverse-shell): Generate reverse and bind shell payloads for bash, Python, PowerShell, netcat and more, with the matching listener command, shell stabilisation steps and CTF post-exploitation quick wins.
- [AI Prompt Injection Lab](https://suhesh.com.np/tools/ai-injection): Practise and study prompt injection, system-prompt leakage and jailbreak techniques against LLM applications, organised by attack category with the defensive control that stops each one.
